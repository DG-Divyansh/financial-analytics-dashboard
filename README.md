# HR Analytics Dashboard

## 📌 Project Overview
This project delivers an interactive HR Analytics solution analyzing employee performance, attrition trends, salary distribution, and attendance rates to enable data-driven HR decision-making.

## 🛠️ Tech Stack & Tools
- **Python**: Pandas, NumPy (Data Cleaning & Preprocessing)
- **SQL**: Database querying & aggregations
- **Power BI**: Interactive KPI visualization & dashboard reporting

## 📊 Key KPIs & Metrics
- **Total Headcount & Department Distribution**
- **Overall & Departmental Attrition Rates**
- **Average Monthly Salary Benchmarking**
- **Workforce Attendance vs. Performance Correlation**
